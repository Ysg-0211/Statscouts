STATSCOUT is a basketball analytics project I built using Python, NumPy, and Pandas.
The main idea behind this project is simple: use basketball statistics to understand how players perform, compare them, and identify their strengths through data.
What it does
Tracks player performance across multiple matches.
Calculates advanced stats like EFG% and TS%.
Ranks players based on their performance.
Looks at recent form and performance trends.
Compares players and generates scouting reports.
Keeps match history and exports data into CSV files.
Built with
Python
NumPy
Pandas
Why I built it
I wanted to explore how data analysis can be used in basketball. STATSCOUT is my attempt to combine my interest in the game with programming and turn raw statistics into something useful.
